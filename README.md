# NeuralPath — Machine Learning Course Landing Page

A responsive landing page for a fictional Machine Learning course
built with HTML, CSS, and vanilla JavaScript.

## About the Project

NeuralPath is a fictional educational brand created to demonstrate
front-end development skills through a modern course sales page.

The project includes:

- Responsive navigation menu
- Course curriculum with interactive modules
- Project showcase section
- Instructor and testimonial sections
- FAQ accordion
- Enrollment modal with client-side form validation
- Responsive layout for desktop, tablet, and mobile

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla)

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/machine-learning-course-landing-page.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No additional dependencies or build tools are required.
